# 브로셔 이미지

전시 브로셔 제출용 이미지(3840×2160, 16:9)다. 기획서의 구도(밤하늘 한가운데 빛나는 별자리 선, 한쪽에 핀치하는 손, 아래에 언덕 실루엣, UI 없음)를 따랐다.

| 파일 | 내용 |
| --- | --- |
| `constellation_brochure_final_3840x2160.png` | **제출용 최종본(GPT 2차 시안).** 아래 두 장을 레퍼런스로 이미지 생성 AI(GPT)가 다시 그린 것을 3840×2160으로 키웠다. 1차보다 하늘 채도가 낮고 능선·호수가 사실적이다 |
| `constellation_brochure_gpt_v1_3840x2160.png` | GPT 1차 시안(보관용) |
| `constellation_brochure_3840x2160.png` | 글자 없는 기본판 |
| `constellation_brochure_3840x2160_title.png` | 왼쪽 아래에 "Constellation / One star, One story" |

- 실제 게임 캡처가 아니라 게임 화면을 바탕으로 그린 대표 이미지다. 하늘은 게임의 하늘 셰이더와 같은 계산식으로 그렸고, 별자리(날아오르는 학)와 손은 게임의 표시 방식(금빛 선, 민트색 손)을 따라 따로 그렸다.
- 제목 글꼴은 프로젝트에 들어 있는 Gowun Dodum(SIL OFL 1.1)이다.
- 브로셔에는 게임명 정도의 간단한 글을 넣어도 된다(소개글은 따로 들어가지 않는다). 제출은 최종본(`_final`)을 쓴다.
- GPT 시안은 원본이 1672×941이라 두 단계로 키우고 살짝 선명하게 했다. 아주 크게 인쇄하면 조금 부드럽게 보일 수 있다.
