# Constellation - One star, One story

핸드트래킹으로 밤하늘의 별을 이어 나만의 별자리를 그리면, AI가 모양을 읽어 이름과 옛이야기를 지어주는 Quest 3 VR 체험입니다.

남서울대학교 제12회 VR·AR 콘텐츠 전시회 출품작입니다.

## 체험 흐름

1. 대기 화면에서 손을 들면 시작
2. "어떤 별자리를 만들까요?" 질문에 아이콘 3개(소원 · 모험 · 소중한 사람) 중 하나 선택
3. 핀치로 하늘의 후보 별을 이어 별자리 그리기
4. 완성 제스처(양손 모으기)로 마치기. 별은 3개 이상 필요
5. 별자리를 2D 이미지로 캡처해 AI에 전송
6. AI가 지어준 별자리 이름과 이야기를 하늘에 표시
7. 결과 카드를 QR로 제공하고 대기 화면으로 복귀

AI 응답이 10초 안에 오지 않거나 형식이 깨지면 키워드별로 미리 만든 이야기로 대신합니다.

## 기술 스택

- Unity, XR Hands (Meta Quest 3 핸드트래킹)
- Cloudflare Workers 중계 서버, Claude API (Haiku 5.5)

## 보안 주의

API 키는 앱이나 이 저장소에 넣지 않습니다. 중계 서버의 비밀 값으로만 보관합니다.
